## 🧩 Temperature Converter
A temperature converter, where the user is able to convert their current temperature into their desired temperature.

Simply input a number into one the of the text boxes and it will convert it to the desired temperature. The converted temperature will appear in the other box that isn't being type in. You could even switch the two boxes to different sides if preferred. 

1. Input a number into one of the text boxes
2. The temperature typed will automatically be converted

## Features
Allow the user to switch the temperature boxes to the other side. Though, they are able to type in either side and the program will automatically convert to another side. 
A small animation will play depending on what temperature is typed in.
